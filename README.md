# Skin Silhouette Aesthetics | Luxury Atelier Engine

A high-fashion clinical aesthetic platform built with React 18, Vite, and Framer Motion. This project features a bespoke "Atelier Nude" color palette, 3D vertical image breakouts, and pixel-perfect Figma fidelity.

## Core Features
- **Deterministic 3-Row Grid:** Guaranteed breakout alignment for clinical results.
- **Asymmetric Horizontal Journal:** Cinema-ratio blog matrix.
- **Nurse-Led Clinical Logic:** Data-driven FAQ and Treatment registries.
- **Responsive Symmetry:** Custom 740px/900px architectural breakpoints.

## Stack
- React 18 (SPA)
- Framer Motion (Animations)
- Vite (Build Tool)
- CSS Variables (Atelier Nude Palette)
